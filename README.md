# SE Selector

ローカルで何度も使える、SE 比較ツールです。

ゲーム制作などで作成した効果音の候補を、ファイル名から自動でグループ化し、
波形・長さ・サイズを確認しながら左右で試聴して絞り込みます。
UI は単一の HTML（CSS / JavaScript 内包）、起動用サーバーは Python 標準ライブラリで構成されています。
音声の読み書きはブラウザの File System Access API で行い、Python はリポジトリ内の静的ファイルを配信します。

**重要: 採用操作は不採用ファイルを直接削除します。Undo・ごみ箱への退避はありません。
最初は必ずバックアップした音声のコピーで試してください。**

## セットアップ

- Python 3.9 以降を用意し、`python --version` で実行できることを確認してください。
- File System Access API に対応したデスクトップ版 Chrome / Edge 系ブラウザを使用します。
- 外部 Python パッケージ、npm、ビルド工程は不要です。依存関係マニフェストはありません。
- 音声素材は同梱していません。比較用のファイルを任意の作業フォルダに用意します。

## 起動

リポジトリのフォルダで実行します。

```powershell
python se_selector_server.py
```

Windows では `se_selector.bat` のダブルクリックでも起動できます。
起動すると通常は `http://127.0.0.1:8765/se_selector.html` を既定のブラウザで開きます。
非対応ブラウザが開いた場合は、端末に表示された URL を Chrome / Edge で開いてください。
ポートが使用中なら、8765 から順に最大 100 ポートの範囲で空きを探します。
終了は起動した端末で `Ctrl+C` を押します。

ポートを指定して、ブラウザの自動起動を止める場合:

```powershell
python se_selector_server.py --port 8766 --no-browser
```

既定の接続先は `127.0.0.1` です。サーバーには認証がなくリポジトリ内を配信するため、
`--host` を変更して外部へ公開しないでください。

## 想定用途

- `slash_a.mp3` / `slash_b.mp3`
- `hit_a.mp3` / `hit_b.mp3`
- `magic_left.wav` / `magic_right.wav`
- `click_01.wav` / `click_02.wav`

のような比較用ファイルを並べて、ペアごとに残す方を選びます。

対象拡張子は `.mp3` / `.wav` / `.ogg` / `.m4a` / `.flac` です。
選択フォルダ直下のみを読み込み、同じベース名・拡張子で接尾辞が対応するペアを比較します。
ファイル名の比較は大文字・小文字を区別しません。

## 操作

- `フォルダを選ぶ`
  - 比較したい SE フォルダを選択
- `A を採用` / `B を採用`
  - 負けた方のファイルを削除
  - あわせて、そのファイル名に `.import` を付けた Godot 用サイドカーファイルも削除
- `Pool`
  - 両方とも `_pool` フォルダへ移動
- `Skip`
  - 今の組み合わせを後回し

## ショートカット

- `Q`: A を再生
- `W`: B を再生
- `1`: A を採用
- `2`: B を採用
- `P`: Pool
- `S`: Skip
- `Space`: 停止

## お気に入り

一度フォルダを選んでから `今のフォルダをお気に入り登録` を押すと、
ブラウザの IndexedDB に名前とフォルダハンドルを保存します。

次回からはお気に入りを押して再オープンできますが、書き込み権限の再許可が必要な場合があります。
同じ名前で保存すると登録を更新し、横の `×` で登録だけを削除できます。
登録はブラウザのプロファイルと接続先 URL（ポートを含む）ごとに別管理です。
ブラウザのサイトデータを消すと登録も失われます。

## コード構成

| ファイル | 役割 |
| --- | --- |
| `se_selector.html` | UI、ペア検出（`detectPairing`）、音声再生・波形描画、ファイル操作、お気に入り保存 |
| `se_selector_server.py` | ローカル静的配信、空きポート探索、ブラウザ起動、CLI 引数 |
| `se_selector.bat` | 自身のフォルダへ移動して Python サーバーを起動する Windows ランチャー |
| `.gitignore` | Python の `__pycache__` と `.pyc` キャッシュを除外 |

## 開発・確認

既存の自動テスト、テストランナー設定、CI 設定はありません。
起動オプションは `python se_selector_server.py --help` で確認できます。
UI を変更した場合は、音声のコピーを使ってペア検出、再生、採用、Pool、Skip、
お気に入りの再オープンと実際のファイル状態をブラウザで確認してください。

## 注意

- Chrome / Edge 系ブラウザ前提です
- ブラウザの File System Access API を使うので、読み書き権限の許可が必要です
- 音声コーデックの再生・波形表示可否はブラウザに依存します
- Pool は音声をコピーして元ファイルと `.import` を削除する処理です。`.import` は移動先へコピーしません
- 移動先に同名ファイルがあると上書きします。コピーと削除は一括トランザクションではありません
- 削除エラーは画面に通知されないため、処理後は実際のファイルも確認してください
- 確認ダイアログ・操作履歴・セッションの復元はなく、Skip の順番も再読み込みで戻ります
- ペア認識は今のところ以下です
  - `_a / _b`
  - `-a / -b`
  - `_left / _right`
  - `-left / -right`
  - `_01 / _02`
